# Security Policy

## Supported versions

The latest released version receives fixes. Use the latest ZIP from Releases.

## Reporting a vulnerability

Please open a private security advisory on this GitHub repository. Do not post cookies, tokens, session data, or sensitive text in a public issue.

Useful details to include:

- Browser and version
- Extension version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Console messages, with tokens removed

## Scope

This extension intentionally uses an undocumented Gemini Web endpoint with your signed in session. It is not an official Google product. Security fixes will focus on local data handling, permission scope, and accidental leakage of session or selection data.
